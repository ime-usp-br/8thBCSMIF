<task name="Post Comment on GitHub">

<task_objective>
This workflow guides the assistant in formulating and posting a comment to a specific GitHub issue using the `gh` CLI. It first gathers the context of the issue and its comment history to ensure the new comment is relevant and well-formatted.
</task_objective>

<detailed_sequence_steps>
# Post Comment on GitHub - Detailed Process

**Important Note:** When executing commands that might produce extensive output or hang the terminal, use `| cat` at the end of the command. Example: `your-command-here | cat`.

## 1. Gather Issue Context

1.  Use the `ask_followup_question` command to ask the user for the number of the issue where the comment should be posted.

2.  After receiving the issue number, execute the command below to get the title, body, and the last 5 comments, providing context for formulating the new comment.

    ```xml
    <execute_command>
    <command>
    # Replace {issue_number} with the number provided by the user.
    gh issue view {issue_number} --json title,body,comments --comments | cat
    </command>
    <requires_approval>false</requires_approval>
    </execute_command>
    ```

## 2. Formulate the Comment

1.  Use the `ask_followup_question` command to ask the user for the content of the comment or if they would prefer the assistant to generate a suggestion based on the issue's context.

2.  If the user requests a suggestion, analyze the context obtained in Step 1 and formulate a clear and objective comment in Markdown.

3.  Present the final comment (provided by the user or generated by the assistant) for final approval before posting.

## 3. Post the Comment

1.  After the comment content is approved, use the `gh` command to post it to the corresponding issue.

    ```xml
    <execute_command>
    <command>
    # Replace {issue_number} with the issue number and "{comment_body}" with the final comment content.
    # Using a HEREDOC ensures that multi-line Markdown formatting is preserved.
    COMMENT_BODY="$(cat <<'EOF'
    {comment_body}
    EOF
    )"
    gh issue comment {issue_number} --body "$COMMENT_BODY" | cat
    </command>
    <requires_approval>true</requires_approval>
    </execute_command>
    ```

## 4. Final Confirmation

1.  After the command is executed, use `attempt_completion` to inform the user that the comment was successfully posted, providing a link to the issue as confirmation.

</detailed_sequence_steps>
